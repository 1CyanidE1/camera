# Кадр — подсказчик композиции для iPhone

Наводишь камеру, приложение в реальном времени анализирует сцену и рисует рамку
лучшего кадра. Дальше два варианта:

- **Быстро:** жмёшь спуск, и приложение снимает полноразмерное фото (до 48 Мп) и само обрезает его по рамке.
- **Как профи:** совмещаешь крестик с точкой в центре рамки и жмёшь «Приблизить ×N».
  Камера доезжает зумом (с переключением на телеобъектив), рамка становится зелёной
  («Идеально — снимай!»), и кадр получается без потери качества.

Рамка **приклеена к сцене**: если двигаешь телефон, она едет вместе с объектом.
Если зумишь, она масштабируется. Сменится она только тогда, когда найдётся кадр
заметно лучше (на 12%+), и он продержится несколько анализов подряд, так что рамка не дёргается.
Если тапнуть по рамке, она закрепится и не сменится вообще.

**Почему этот кадр.** Кнопка «?» вверху включает объяснения. На рамке появляются жёлтое кольцо
в точке третей (или в центре), куда встал главный объект, точка самого объекта и обводка лиц.
Под рамкой идёт список причин: «Главное на пересечении третей», «Отрезано 52% площади, а интересного
сохранено 91%», «Лицо целиком», «Эстетика по оценке Apple: 7.4 из 10». Компромиссы помечены оранжевым.

**Галерея внутри приложения.** Тап по миниатюре открывает снятые кадры: листаешь свайпом, увеличиваешь
щипком или двойным тапом. Переключатель «Исходник с рамкой» показывает, что было в видоискателе
и что из этого вырезано. Здесь же видны причины, которые были в момент съёмки. Можно поделиться снимком
или удалить его из приложения (в «Фото» он останется). Внутри приложения хранится копия до 3072 px
по длинной стороне, полноразмерный снимок лежит в «Фото».

## Как это устроено

| Что | Как часто | Чем |
|---|---|---|
| Слежение за сдвигом сцены | каждый кадр (30 к/с) | интегральные проекции яркости, < 1 мс |
| Анализ композиции | ~6 раз в секунду | Apple Vision: карта внимания, лица, люди → перебор ~5000 кропов (7 форматов × 7 масштабов × сетка) через интегральное изображение |
| Эстетическая оценка | ~1,5 раза в секунду | Apple Vision `CalculateImageAestheticsScoresRequest` (iOS 18) для 2–3 лучших кропов |

Оценка кропа учитывает: сколько «интересного» попало в кадр и сколько пустоты отрезано,
правило третей и центральную композицию, интересное у краёв (не режем объекты),
лица (никогда не режем, запас над головой, глаза около верхней трети), людей в полный рост,
минимальный размер кропа (качество), ориентацию телефона.

Ещё есть уровень горизонта: когда телефон ровно, он становится жёлтым.
Тап мимо рамки ставит фокус и экспозицию в эту точку, щипок — зум.
Форматы: Авто / 4:5 / 3:4 / 2:3 / 1:1 / 3:2 / 16:9, с учётом того, как держишь телефон.

Требования: iPhone с iOS 18 или новее.

## Установка без Mac

Код собирается на облачном Mac от GitHub (бесплатно), а на iPhone ставится с Windows
через Sideloadly. Mac для этого не нужен.

### 1. Собрать приложение на GitHub (один раз ~10 минут)

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Создай новый репозиторий: **New repository** → имя, например, `kadr`.
   - **Public** — сборки бесплатные и без лимита.
   - **Private** — тоже бесплатно, но лимит около 20–25 сборок в месяц (минуты на Mac считаются ×10).
3. Загрузи в него все файлы этой папки (вместе с папкой `.github`).
   Проще всего так: на странице репозитория нажми **uploading an existing file**
   и перетащи всё содержимое папки. Или пришли мне ссылку на пустой репозиторий, и я залью сам.
4. Открой вкладку **Actions**: там автоматически запустится сборка **Build iPhone app** (5–8 минут).
5. Когда появится зелёная галочка, открой сборку, внизу в разделе **Artifacts** скачай
   `FrameFinder-ipa` и распакуй zip. Внутри лежит **FrameFinder.ipa**.

Каждый раз, когда код меняется и заливается в репозиторий, GitHub собирает новую версию сам.

### 2. Поставить на iPhone с Windows (Sideloadly)

1. Установи **iTunes** и **iCloud** *с сайта Apple* (не из Microsoft Store), так требует Sideloadly.
2. Скачай и установи **Sideloadly** с [sideloadly.io](https://sideloadly.io).
3. Подключи iPhone кабелем к ПК и на телефоне нажми «Доверять этому компьютеру».
4. В Sideloadly перетащи `FrameFinder.ipa`, впиши свой Apple ID (обычный, бесплатный) и нажми **Start**.
   Пароль вводишь только ты, в окне Sideloadly. Он уходит в Apple для подписи приложения.
5. На iPhone:
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл.** (телефон перезагрузится);
   - **Настройки → Основные → VPN и управление устройством** → твой Apple ID → **Доверять**.
6. Запускай «Кадр» 📸

**Ограничение бесплатного Apple ID:** приложение работает 7 дней, потом его нужно переподписать.
Для этого достаточно ещё раз нажать Start в Sideloadly (данные не теряются). В Sideloadly можно
включить автообновление по Wi-Fi, тогда он сам будет продлевать подпись, пока ПК и телефон в одной сети.

**Если не хочется возиться каждую неделю:** платный Apple Developer ($99/год) позволяет ставить
через TestFlight на год. Сборку в GitHub можно доработать так, чтобы она сама отправляла
приложение в TestFlight, и это тоже без Mac.

## Структура

```
project.yml                 — описание Xcode-проекта (генерируется XcodeGen в облаке)
.github/workflows/build.yml — облачная сборка → FrameFinder.ipa
FrameFinder/
  App/       — точка входа, модель экрана (жесты, зум, съёмка, уровень)
  Camera/    — камера (AVFoundation), съёмка, кроп и сохранение в «Фото»
  Analysis/  — Vision-анализ, оценка композиции, «липкая» рамка, слежение за сдвигом
  UI/        — видоискатель, рамка, панели
```

Настройки, которые стоит покрутить после первых тестов на живых сценах:
- `CompositionEngine.switchMargin` / `switchStreak` — насколько «упрямая» рамка;
- `CameraPipeline.analysisInterval` — частота анализа;
- веса в `CompositionScorer.score(...)` — вкус композиции.
